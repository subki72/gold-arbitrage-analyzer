# Contributing to Gold Arbitrage Analyzer

We welcome contributions adhering to institutional code quality and testing standards.

## Local Setup

```bash
git clone https://github.com/subki72/gold-arbitrage-analyzer.git
cd gold-arbitrage-analyzer
make install
```

## Verification Gates

```bash
make lint
make test
make build
```

## Pre-Commit Hooks

```bash
pip install pre-commit
pre-commit install
```
